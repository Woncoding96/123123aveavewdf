# 반배정 프로그램

엑셀 양식 파일을 불러와 새 학급을 배정하는 웹앱입니다.
모든 처리는 브라우저 안에서만 이루어지며, 학생 정보가 서버로 전송되지 않습니다.

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 디자인
- `app.js` — 배정 로직 (ExcelJS 포함)

## 사용 방법

1. 사이트에 접속합니다.
2. 반배정 양식 엑셀 파일(.xlsx)을 끌어다 놓거나 클릭해서 선택합니다.
3. 학급 수와 배정 기준을 정한 뒤 **배정하기**를 누릅니다.
4. 배정안을 비교하고 엑셀로 저장합니다.
